Release guides

Build from a code change

Run an existing CI job and trace its build artifact back to the commits it contains.

↗

Distribute and record the version

Match the Git tag to the build number. Use the version distributed through Google Play or TestFlight as the reference for everything that follows.

↗

Update the stores

Use the changes in that version to write release notes, update store images and prepare the review submission.

↗

Create promotional material

Turn a feature that shipped into promotional copy and a video showing how it works.

↗

Publish to your channels

Publish the finished material to Facebook, Instagram, Threads, YouTube and TikTok in one approved call, and follow the response.

↗

Respond to customers

Read a store review and check which version contains the fix before drafting a reply.
