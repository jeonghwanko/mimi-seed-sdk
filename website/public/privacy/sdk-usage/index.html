Optional SDK usage measurement

Off by default. Run mimi-seed telemetry on to participate, and mimi-seed telemetry off to stop. The environment variable MIMI_SEED_TELEMETRY=0 always disables transmission.

With your consent, the CLI sends a random installation ID, a project-path hash with a private local salt, a random run ID, CLI version, OS, CI flag, framework category, command, outcome, duration, mobile platforms and finding codes. The salt never leaves your machine. These are pseudonymous identifiers, not a count of people. No source, paths, app IDs, credentials, free-text errors or store data are included.

Reports go to the Mimi Seed web console after a command finishes. Transmission has an 800 ms timeout and never changes the check result. Crashes and network failures can be missing, so reported runs are not a complete start-to-finish funnel.

Events are kept for up to 90 days, with expired rows removed on ingestion or the maintenance report. IP addresses are used temporarily for request rate limits; they are not written to the usage table. Hosting infrastructure can keep standard request logs. Turning off resets the local measurement ID; it does not delete previously received events. Contact the service to request deletion using your installation ID from the local telemetry settings.
