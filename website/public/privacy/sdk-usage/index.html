Optional SDK usage measurement

Off by default, and sent only to a team console. Set MIMI_SEED_WEB_BASE to your team console's address first, then run mimi-seed telemetry on to participate and mimi-seed telemetry off to stop. Without a team console, telemetry on changes nothing and exits with an error. The environment variable MIMI_SEED_TELEMETRY=0 always disables transmission.

With your consent, the CLI sends a random installation ID, a project-path hash with a private local salt, a random run ID, CLI version, OS, CI flag, framework category, command, outcome, duration, mobile platforms and finding codes. The salt never leaves your machine. These are pseudonymous identifiers, not a count of people. No source, paths, app IDs, credentials, free-text errors or store data are included.

Reports go only to the team console named in MIMI_SEED_WEB_BASE, after a command finishes. Mimi Seed itself does not collect them. Transmission has an 800 ms timeout and never changes the check result. Crashes and network failures can be missing, so reported runs are not a complete start-to-finish funnel.

How long events are kept, and how IP addresses and request logs are handled, are set by the operator of that team console. Turning measurement off resets the local measurement ID; it does not delete events already sent. To request deletion, note the installationId in ~/.mimi-seed/telemetry.json before running telemetry off (turning off erases it), then contact the console's operator.

한국어: 기본 꺼짐이며, 팀 콘솔로만 전송합니다. 먼저 MIMI_SEED_WEB_BASE에 팀 콘솔 주소를 지정한 뒤 mimi-seed telemetry on으로 켜고, 동의한 경우에만 가명 설치 ID·프로젝트 해시·실행 결과를 그 콘솔로 보냅니다. 원본 경로·앱 식별자·소스·인증정보는 전송하지 않습니다. 보관 기간과 삭제는 그 콘솔 운영자의 조건을 따릅니다. 삭제를 요청하려면 telemetry off 전에 ~/.mimi-seed/telemetry.json의 installationId를 적어 두세요(끄면 지워집니다). mimi-seed telemetry off 또는 MIMI_SEED_TELEMETRY=0으로 중단할 수 있습니다. 집계는 동의한 실행만 포함하며 사용자 전체를 뜻하지 않습니다.
