Mimi Seed
가이드 GitHub English

코드에서 출시로,출시에서 고객에게.

Mimi Seed는 코드와 빌드 기록을 바탕으로 모바일 앱을 운영하는 SDK입니다. 어떤 변경이 어느 버전에 들어갔는지 확인하고, 그 기록으로 업데이트 소식을 쓰고 홍보 영상을 만들고 고객에게 답합니다.

Android·iOS 배포와 버전 기록

스토어 업데이트와 심사

↗

홍보 글과 영상 제작

새 기능을 사용자가 경험하는 장면으로 풀어 홍보 글과 영상 소재를 만듭니다.

↗

채널 게시와 운영

↗

리뷰와 고객 응대
