# PDF 디자인 검수

독자가 읽고 결정할 내용을 기준으로 페이지를 구성한다. 사용자의 목적, 문서 내용, 기존 시각 언어를 존중한다. PDF 제작 스킬이 있다면 생성과 기술 검증에 함께 사용한다.

1. 독자가 가장 먼저 내릴 결정을 적는다. 제안서라면 첫 페이지에서 제안 내용, 판단에 필요한 근거, 다음 행동을 찾을 수 있게 한다. 견본이 납품물을 이해하는 데 도움이 되면 지면에 넣는다.
2. 페이지를 구성하기 전에 서체를 결정한다. 실제 제목, 빽빽한 본문, 날짜와 금액을 넣어 확인한다. 사용할 문자 체계를 지원하는 서체를 문서에 임베딩한다. 한글 PDF 또는 타이포그래피 중심의 수정은 [타이포그래피와 문서 UX](references/typography-and-ux.md)를 참고한다.
3. 구체적인 소제목을 붙이고 관련 정보를 같은 기준선에 맞춘다. 글자의 크기와 굵기, 여백으로 읽는 순서를 만든다. 반복되는 제목과 장식성 문구를 덜어내고, 예시 데이터는 한 곳에서 명확히 표시한다.
4. 최종 PDF를 렌더링해 읽는 크기와 배포 화면에서 검수한다. 블로그나 메시지에 붙이는 문서는 스마트폰 폭에서도 제목, 주요 내용, 다음 행동의 순서가 보이는지 확인한다. 잘림, 깨진 글자, 부자연스러운 줄바꿈, 간격과 정렬을 확인한다. 필요한 서체가 임베딩됐는지 확인하고 대표 문장과 수치를 실제로 복사해 본다.
5. 검수에서 발견한 문제를 고치고 다시 렌더링한다. 첨부 파일을 교체했다면 저장된 문서를 열어 의도한 파일이 들어갔는지 확인한다.
